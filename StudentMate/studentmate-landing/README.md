# StudentMate Landing (Vite + React + TypeScript)

This folder contains a standalone landing page app scaffolded to demonstrate the animated intro/landing page using Tailwind, Framer Motion and Lucide icons.

To run:

```bash
cd studentmate-landing
npm install
npm run dev
```

Files added:
- `src/components/ui/background-gradient-animation.tsx` — background animation
- `src/components/ui/demo.tsx` — layout wrapper
- `src/components/Hero.tsx` — hero section
- `src/components/FeaturesGrid.tsx` — features preview
- `src/components/Navbar.tsx` — translucent navbar
- Tailwind + Vite config
